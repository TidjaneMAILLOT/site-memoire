PARTIE DOCUMENTATION - TERMINALE NSI

1. Récursivité

1.1. Définition

Une fonction récursive est une fonction qui s'appelle elle-même pour résoudre un problème. Elle décompose le problème en sous-problèmes de plus en plus petits, jusqu'à atteindre un cas qui peut être résolu directement.

1.2. Exemple classique : la factorielle

La factorielle d'un entier naturel n, notée n!, est définie par :

0! = 1 et n! = n × (n - 1)! pour n > 0

def factorielle(n):
    if n == 0:              # cas de base
      return 1
    return n * factorielle(n - 1)  # appel récursif

Ainsi, factorielle(4) calcule 4 × 3 × 2 × 1 et renvoie 24.

1.3. Condition d'arrêt

Toute fonction récursive doit posséder un cas de base, c'est-à-dire une condition qui arrête les appels récursifs. Sans cette condition, la fonction s'appelle indéfiniment et provoque une erreur lorsque la profondeur maximale de récursion est atteinte.

1.4. Pile d'appels

Chaque appel de fonction est placé dans une pile d'appels. Les appels sont retirés dans l'ordre inverse de leur arrivée : le dernier appel effectué est le premier à se terminer.

Pour factorielle(3), la pile évolue ainsi :

factorielle(3)
    → 3 * factorielle(2)
      → 2 * factorielle(1)
        → 1 * factorielle(0)
          → 1
        → 1
      → 2
    → 6

1.5. Récursivité et itération

Un problème récursif peut souvent être résolu avec une boucle. La version itérative utilise généralement moins de mémoire, tandis que la version récursive peut être plus simple à comprendre lorsque le problème est naturellement composé de sous-problèmes.

def factorielle_iterative(n):
    resultat = 1
    for valeur in range(2, n + 1):
      resultat *= valeur
    return resultat

1.6. Exemple : suite de Fibonacci

La suite de Fibonacci est définie par F(0) = 0, F(1) = 1 et F(n) = F(n - 1) + F(n - 2).

def fibonacci(n):
    if n <= 1:
      return n
    return fibonacci(n - 1) + fibonacci(n - 2)

Cette version effectue plusieurs fois les mêmes calculs. Sa complexité est exponentielle. La mémorisation permet de conserver les résultats déjà calculés :

def fibonacci_memo(n, memo=None):
    if memo is None:
      memo = {}
    if n <= 1:
      return n
    if n not in memo:
      memo[n] = fibonacci_memo(n - 1, memo) + fibonacci_memo(n - 2, memo)
    return memo[n]

1.7. Bilan

  • Une fonction récursive contient au moins un cas de base et un appel récursif.
  • La pile d'appels mémorise les fonctions en attente de terminaison.
  • La récursivité est adaptée aux structures naturellement imbriquées, comme les arbres.
  • La mémorisation évite de recalculer plusieurs fois les mêmes résultats.
